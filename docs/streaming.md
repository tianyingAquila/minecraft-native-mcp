# 可选直播集成

核心 MCP 与直播平台无关。直播控制台在 `npm start` 时运行，默认只监听 `127.0.0.1:21940`。

## 抖音直播伴侣

1. 使用游戏进程素材选择 Minecraft Java 客户端，按画布比例缩放。
2. 鲸鱼、气泡、小字由本仓库客户端模组在游戏HUD绘制；无需打开绿幕浏览器。
3. 保持游戏窗口打开，不最小化。平台的捕获表现仍需在本机验证。
4. 只保留需要的游戏声音。开始/结束推流需要在直播软件单独操作；控制台到时只暂停游戏。

可用 `FISH_COMPANION_PATH` 指定直播伴侣启动程序路径，供控制台“打开直播伴侣”使用。未设置时可直接手动打开直播软件。

余额提示每3–5分钟显示，操作气泡来自模型与动作同次提交的 `say`，真实事件可用 `reaction`。内置自主循环支持这些元数据；独立MCP客户端默认只控制游戏，如需同类显示可在调用层接入事件，不必修改Minecraft动作本体。

## 其他平台

可以用 OBS 等软件捕获游戏内HUD，也可开发独立输出适配器。已有 `/api/overlay` 数据结构可作为参考，不包含控制错误、私有凭据或暂停原因。备用网页挂件保留，但某些Windows捕获方式会在完全遮挡后冻结网页，优先使用游戏内绘制。

当前不支持直播评论接收、自动回应或观众控制。没有一键平台登录、自动推流或跨平台聊天承诺。
