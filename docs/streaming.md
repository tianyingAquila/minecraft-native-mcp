# 可选直播集成

游戏左上角常驻“当前肥鱼的目标”，下方是模型通过set_goal写入的阶段成果（最多100字符），长句自动换行；它不会随行动气泡消失。模型每轮看到相同现值，完成或阶段策略变化时才修改。内容与世界当前目标一起保存，不增加独立模型请求。关闭直播扩展同时关闭目标板、鲸鱼和气泡。

核心 MCP 与直播平台无关，默认是普通自主游玩。先安装基础版，再安装独立的 `dsh-minecraft-stream` 扩展（命令见首页）；重开 DSH，暂停游戏后点击“直播扩展”启用。两者共用 `127.0.0.1:21940` 控制台。

## 抖音直播伴侣

1. 使用游戏进程素材选择 Minecraft Java 客户端，按画布比例缩放。
2. 鲸鱼、气泡、小字由本仓库客户端模组在游戏HUD绘制；无需打开绿幕浏览器。
3. 保持游戏窗口打开，不最小化。平台的捕获表现仍需在本机验证。
4. 只保留需要的游戏声音。开始/结束推流需要在直播软件单独操作；控制台到时只暂停游戏。

可用 `FISH_COMPANION_PATH` 指定直播伴侣启动程序路径，供控制台“打开直播伴侣”使用。未设置时可直接手动打开直播软件。

余额提示每3–5分钟显示，操作气泡来自模型与动作同次提交的 `say`，真实事件可用 `reaction`。内置自主循环支持这些元数据；独立MCP客户端默认只控制游戏，如需同类显示可在调用层接入事件，不必修改Minecraft动作本体。

## 其他平台

可以用 OBS 等软件捕获游戏内HUD，也可开发独立输出适配器。已有 `/api/overlay` 数据结构可作为参考，不包含控制错误、私有凭据或暂停原因。备用网页挂件保留，但某些Windows捕获方式会在完全遮挡后冻结网页，优先使用游戏内绘制。

当前不支持直播评论接收、自动回应或观众控制。没有一键平台登录、自动推流或跨平台聊天承诺。

## 备用绿幕与恢复

在直播控制台取消“游戏内鲸鱼与气泡”并保存，再打开“备用浏览器挂件”。在伴侣添加素材 → 窗口，选择标题包含“大肥鱼绿幕”的浏览器窗口；关闭鼠标捕获，裁掉浏览器工具栏，使用绿幕/色度抠像移除绿色，放在游戏素材上方。某些捕获方式在浏览器完全被遮挡时会冻结，不建议把这条备用路径作为默认方案。

优先使用游戏内绘制：在伴侣添加素材 → 游戏进程，选当前 Minecraft 的 java.exe；如画面偏小，在素材变换中使用平铺/适配画布。只需保留这一项游戏素材，不再叠加浏览器挂件。

不直播时，暂停后点“关闭直播扩展，返回普通游玩”。卸载扩展：`dsh plugin --profile desktop remove dsh-minecraft-stream`，然后重开 DSH。基础游戏与存档保留。
