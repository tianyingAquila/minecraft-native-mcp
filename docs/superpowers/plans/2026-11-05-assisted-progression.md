# 辅助通关 Implementation Plan

**Goal:** 随机世界保留原生第一视角，提供明确标注的资源/结构/生物位置提示、两格高台猪灵交易和持弩猪灵中立辅助。

**Architecture:** 沿用认证客户端桥，原生接口报告同机服务端请求目录；辅助请求通过每世界一次性JSON文件交给服务端tick处理，不新增监听端口、系统服务或常驻进程。客户端动作仍使用原生背包、投掷、跳跃、放置和寻路；交易只认新增背包物品。复用MIT上游独立进度记录，保留许可，禁止把Mineflayer接口假装成可直接用于Fabric。

**Tech Stack:** Node ESM、Java21、Fabric/Mixin、Minecraft1.21系列。

**Spec:** 本次用户明确授权：辅助通关；随机种子；普通持弩猪灵忽略大肥鱼；近战猪灵照常攻击；搭高两格逐枚投金锭交易、识别掉落；直接提供岩浆湖、地狱堡垒和目标生物提示。无需新增审批。

## Global Constraints
- 不启动付费模型长局；真实验证使用独立测试存档，原世界保留暂停。
- 不新增系统服务、端口或开机启动；不提交世界、凭据和生成产物。
- 日常项目与公开源码同步；兼容分支集中在现有构建脚本，逐版本编译。
- 提示区分服务端辅助、已加载生物及有限半径未找到；不把坐标当作安全路线。
- 交易只投金锭，逐枚核对，预算有限；取消后无后续投掷或移动。

## Review Focus
- 空背包、无建筑块、无金锭或儿童猪灵：执行前拒绝。
- 地狱以外、脚下不稳、头顶受阻和附近苦力怕：不得盲搭塔。
- 金锭消失但没有交换产物：记录花费，不能报告成功或自动重投同一笔。
- 产物留在地上、被其他生物捡走、拾取背包已满：区分目击与获得。
- 服务端不支持/查询超时/取消/换维度：有限失败、清理请求，原游戏不假成功。
