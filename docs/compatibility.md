## 2026-11-10开发源码：分段生存验收

在 Minecraft Java 1.21.4 的独立测试世界给出阶段目标和起始条件，由真实 DeepSeek 从常规工具中选择动作。成功依据为实际背包、方块、维度或实体状态。此前已经确认：空背包做齐五件石器、铁剑狩猎得11块生牛肉、批量做出6块牛排、合并背包并保留物品、用铁镐采得钻石、用黑曜石建地狱门并往返、取得烈焰棒、补眼并穿过末地门，以及由末地出生平台到达天然主岛。部分条件分别在独立世界验证。裸水晶和带铁栏杆水晶也各自通过受控测试。带栏杆场景中，模型选择拆除工具，实际靠近柱脚、搭四格、挖开铁栏杆、确认水晶消失并拆柱回到原地面。

主世界夜间近地面场景中，DeepSeek 一次选择连续近战和指定拾取，原生动作确认击杀，背包新增1颗末影珍珠。此前两次高空场景瞬移后丢失目标，近地面不带拾取的试验确认了5次击杀，但背包未得到珍珠。 单独的五格断口试验用 `bridge_gap` 实际放置五块末地石，再站到对岸。 下界试验穿金靴，用近战猪灵搭台交易，最后一次交换用2枚金锭取得并拾回4颗珍珠，整段实际消耗28枚。

自然落地的龙战专项通过一轮近战和撤离。为隔离动作，在已清除水晶、龙自然落地后布置近处生存起点，等第一次动作开始才解冻。DeepSeek 第二次接战挥剑，实际龙血190→183，角色撤到有支撑、无龙息的位置，结束血量5.8/20。普通进场时曾靠近失败并死亡，尚不能依此判断能稳定打完整场龙战。

自动检查119项通过，客户端和服务端模组已重新编译12个版本，运行文件校验通过。实机专项在1.21.4完成。

这些场景给定可达矿石、目标生物或门的邻近位置。随机世界长距离找矿、找堡垒和末地门房间、连续自然塔群作战以及完整通关留给独立监督局。证据目录为 `outputs/smoke/staged/`，分段设计见[验收计划](superpowers/plans/2026-11-09-staged-progression-validation.md)。
